这三件是真机功能的硬前提，按顺序做：

要做的事在哪做不做会怎样
解除域名第三方托管，然后配三类合法域名：
request / uploadFile / downloadFile → https://api.dtzai.cn
socket 留空，不要填（填 https 会报「协议头非法」）		 小程序后台 →「开发管理 → 开发设置 → 服务器域名」
（现在是「已托管给第三方」，要先在账号设置里解除）		 真机上传照片、录音全失败（今天的故障根因）
《用户隐私保护指引》声明这四项：
手机号 · 麦克风 · 相册（含摄像头）· 从聊天选择文件		 小程序后台 →「设置 → 服务内容声明 → 用户隐私保护指引」 手机号授权弹不出来，注册流程走不完
服务类目 + ICP 备案：记账/财务类目需要相应资质 小程序后台 →「设置 → 基本设置 → 服务类目」 提交审核会被驳回，上不了线
